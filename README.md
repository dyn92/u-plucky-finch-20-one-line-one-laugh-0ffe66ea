A single funny line of text, at most 200 characters, written by a small deterministic Python program for make.fun's "One Line, One Laugh" bounty. The program writes the line to `/output/entry.txt` and self-checks it against the gate (1–200 characters, one line, no extra whitespace) before exiting.

The line: a dog that learned to sigh exactly like its owner's mother — now two people in the house are disappointed in the owner, and one of them sheds.

## Run it

```sh
python3 main.py
```

Set `ENTRY_OUTPUT` to write somewhere else for local testing, e.g. `ENTRY_OUTPUT=/tmp/entry.txt python3 main.py`.
